# دیده‌بان کدال و خبر بازار — راهنمای فارسی

نسخهٔ ۰٫۱٫۰ · بدون هیچ وابستگی بیرونی · اجرا روی ویندوز یا لینوکس · بدون اینترنت هم کار می‌کند

## این برنامه چه کار می‌کند

۱. اطلاعیه‌های کدال و خبرهای بازار را می‌خواند (از اینترنت، از فایل، یا از دادهٔ نمونه).
۲. هر مورد را دسته‌بندی می‌کند: افزایش سرمایه، تعدیل، توقف و بازگشایی، قرارداد، دعوی، تبعی و بقیهٔ دوازده دسته.
۳. جهت را حدس می‌زند (مثبت، منفی، خنثی) و یک **امتیاز ۰ تا ۱۰۰** می‌دهد.
۴. برای هر مورد توضیح می‌دهد **چرا مهم است** و اثرش روی ابزار مشتقه را یادآوری می‌کند.
۵. گزارش HTML فارسی و راست‌به‌چپ می‌سازد، فهرست هشدارها را در پایگاه‌داده نگه می‌دارد، و در صورت تمایل به تلگرام یا بله می‌فرستد.

## این برنامه چه کاری نمی‌کند

- **سفارش نمی‌فرستد.** معاملات الگوریتمی خودکار در بورس و فرابورس ایران مجاز نیست؛ این برنامه «دستیار تصمیم» است و تصمیم نهایی با انسان است.
- سود تضمین نمی‌کند و هیچ‌جا عدد سود وعده نمی‌دهد. امتیاز، فقط ترکیبی از نوع رویداد، تازگی و وجود عدد کمّی است.

## راه‌اندازی (سه دقیقه)

پایتون ۳٫۱۰ یا بالاتر لازم است. روی ویندوز از سایت رسمی پایتون نصب کنید و در هنگام نصب تیک «Add Python to PATH» را بزنید. هیچ بستهٔ اضافی لازم نیست و هیچ اتصالی به پی‌پی‌آی وجود ندارد.

```bash
python kodal_alert.py selftest      # آزمون سلامت (۴ بررسی)
python kodal_alert.py demo          # اجرای کامل روی دادهٔ نمونهٔ آفلاین
python -m unittest discover -s tests   # ۲۶ آزمون واحد
```

پس از اجرای `demo`، پروندهٔ `data/demo-report.html` را در مرورگر باز کنید.

## اجرای واقعی

```bash
# یک بار: از کدال و یک فید خبری
python kodal_alert.py run --source codal --source rss:https://www.farsnews.ir/rss

# دوره‌ای: هر ۱۵ دقیقه
python kodal_alert.py watch --minutes 15 --source codal

# ورود دستی اطلاعیه‌ها (وقتی اینترنت یا سامانه در دسترس نیست)
python kodal_alert.py import my-announcements.json

# گزارش و آمار
python kodal_alert.py report --limit 200
python kodal_alert.py stats
```

ورود دستی، ستون فقرات پایداری این برنامه است. اگر اینترنت قطع شد، کافی است اطلاعیه‌ها را در یک پروندهٔ JSON یا CSV بریزید و همان را وارد کنید. قالب JSON:

```json
[{"title": "افزایش سرمایه ۴۵۰ درصدی", "symbol": "خساپا", "company": "سایپا",
  "source": "کدال", "published_at": "2026-09-22 09:10:00", "url": "https://codal.ir/...",
  "body": "متن کامل اطلاعیه"}]
```

و قالب CSV با سرسطر `title,symbol,company,source,published_at,url,body`.

## منابع داده و شرایط ایران

| منبع | چگونه | هزینه |
|---|---|---|
| کدال | تنظیم‌شده در `config.json` با نوع `codal` | رایگان |
| فید خبری داخلی | نوع `rss` با نشانی فید | رایگان |
| فایل دستی | نوع `file` یا زیرفرمان `import` | رایگان |
| ریزمعاملات و دادهٔ تاریخی تجاری | افزودن نشانی وب‌سرویس و کلید در `config.json` | پرداختی با ریال یا کلید آزمایشی |
| قیمت لحظه‌ای سهام و آپشن | از کتابخانه‌های `tsetmc-api` و `codal-tsetmc` (نصب با `pip install tsetmc-api`) در مرحلهٔ بعد | رایگان |

**نکتهٔ مهم تجربی:** سامانه‌های ایرانی از بیرون ایران (سندباکس خارجی) پاسخ نمی‌دهند؛ این برنامه باید **از داخل ایران** اجرا شود. به همین دلیل، حالت آفلاین و ورود دستی از ابتدا در برنامه گذاشته شده است.

## لایهٔ هوش مصنوعی (اختیاری)

حالت پیش‌فرض `none` است و همه‌چیز با قواعد فارسی کار می‌کند؛ در گزارش، برچسب «شاهد محلی (قاعده‌محور)» می‌خورد. سه گزینهٔ دیگر:

- **Ollama محلی:** رایگان، بدون کلید، بدون تحریم. اگر رایانه‌تان ۸ گیگابایت رم یا بیشتر دارد: `ollama pull qwen2.5:7b` و در `config.json` مقدار `provider` را `ollama` بگذارید.
- **Jev/TypeSafe:** برای وقتی که کلید دارید. کلید را در متغیر محیطی `TYPESAFE_API_KEY` بگذارید، نه در پروندهٔ تنظیمات.
- **OpenRouter:** با متغیر محیطی `OPENROUTER_API_KEY`.

اگر کلید نبود یا سرویس جواب نداد، برنامه با همان قواعد فارسی کار می‌کند و فقط برچسب منبع را عوض می‌کند. هیچ‌وقت خروجی مدل، «توصیهٔ معامله» نیست؛ فقط خلاصهٔ ساخت‌یافتهٔ رویداد است.

## تنظیمات مهم `config.json`

| کلید | معنا | پیش‌فرض |
|---|---|---|
| `watchlist` | نمادهایی که همیشه بررسی می‌شوند | خساپا، شپنا، فولاد، وبملت، شستا، اهرم، طلا، زعفران |
| `min_score_to_alert` | کف امتیاز برای هشدار | ۴۵ |
| `proxies` | پروکسی برای دسترسی به بیرون | خالی |
| `timeout_seconds` و `retries` | رفتار شبکه | ۱۵ و ۲ |
| `notifiers` | کنسول، فایل، تلگرام، بله | کنسول و فایل روشن |

## زمان‌بندی خودکار

- ویندوز: `run-daily.bat` را بسازید (در همین پوشه هست) و در «Task Scheduler» روزهای شنبه تا چهارشنبه ساعت ۸:۵۰ و ۱۲:۴۰ اجرا کنید.
- لینوکس: `*/15 8-12 * * 0-4 python3 /path/kodal_alert.py run --source codal`

## قطعی برق و اینترنت

- هر فراخوانی شبکه، timeout و سه تلاش دارد و پاسخ‌ها در `data/cache/` می‌مانند؛ اگر سامانه نخوابد، برنامه از حافظهٔ نهان کار می‌کند.
- پایگاه‌داده SQLite است و در برابر بستهٔ ناگهانی مقاوم؛ اجرای بعدی، کار ناتمام را ادامه می‌دهد.
- هر رکورد کلید یکتای خودش را دارد؛ اجرای دوباره باعث تکرار هشدار نمی‌شود.

## امنیت و اخلاق کار

- کلیدها فقط در متغیر محیطی، هرگز داخل `config.json` یا کد.
- این ابزار هیچ سفارشی نمی‌فرستد؛ پس رمز سامانهٔ معاملاتی را در هیچ‌جای این پروژه نگذارید.
- از اطلاعات نهانی استفاده نکنید و خروجی را به‌عنوان «توصیهٔ سرمایه‌گذاری» به دیگران نفروشید؛ فروش سیگنال در ایران مسئولیت حقوقی دارد.
