## اجرا

```bash
cd MATERIALS/money/tools
python3 derivatives_scout.py --self-test        # خودآزمون ریاضی (۶ بررسی)
python3 derivatives_scout.py --demo             # سناریوی نمونه با اعداد فرضی

```

قالب پروندهٔ ورودی:

```json
{
  "name": "بازار امروز",
  "hurdle": 0.39,
  "rows": [
    {"name": "باکس اسپرد نماد الف", "kind": "box",
     "call_low": 300, "put_low": 420, "call_high": 180, "put_high": 560,
     "strike_low": 1200, "strike_high": 1500, "days": 45,
     "liquidity_contracts_per_day": 120, "spread_pct": 0.02},
    {"name": "آتی صندوق طلا", "kind": "basis",
     "spot": 20000, "future": 22800, "days": 60, "storage_annual": 0.0},
    {"name": "تبعی", "kind": "tabei",
     "stock_price": 50000, "put_price": 200, "strike": 62500, "days": 90},
    {"name": "تساوی پوت‌کال", "kind": "parity",
     "call": 420, "put": 380, "spot": 9000, "strike": 9000, "days": 30, "rate": 0.39}
  ]

```

`kind` می‌تواند `box`، `basis`، `tabei`، `parity` یا `covered_call` باشد. نرخ سد (`hurdle`) را با بازده مؤثر صندوق درآمد ثابت همان روز پر کنید، نه با عدد ثابت.

## محدودیت‌ها (صادقانه)

- اعداد `--demo` **ساختگی** هستند و فقط برای نمایش کارکرد ابزار؛ هیچ‌کدام قیمت واقعی بازار نیستند.
- خروجی ابزار «تفاوت ریاضی با نرخ سد» است. ریسک نکول ناشر، ریسک اجرای هم‌زمان پاها، صف سفارش و توقف نماد در آن لحاظ نشده.
- داده‌های ورودی (قیمت‌های سهام، آپشن، آتی و گواهی سپرده) باید از سامانهٔ کارگزاری یا پروندهٔ رسمی بازار همان روز تأمین شود؛ ابزار خودش داده جمع نمی‌کند.

## وضعیت اعتبار اعداد قانونی

- **بررسی‌شده در همین نوبت (سپتامبر ۲۰۲۶):** کارمزد معاملهٔ آپشن ۰٫۱۰۳ درصد، کارمزد اعمال ۰٫۰۵ درصد، مالیات تسویهٔ فیزیکی ۰٫۵ درصد؛ کارمزد سهام خرید ۰٫۴۶۴ درصد و کسورات فروش ۰٫۹۶۴ درصد؛ معافیت مالیاتی مشتقه؛ بازده مؤثر صندوق‌های درآمد ثابت شهریور ۱۴۰۵ در محدودهٔ ۳۹ تا ۴۰ درصد؛ تورم سالانه رسماً نزدیک ۷۰ درصد گزارش‌شده؛ نرخ تضمین عرضه‌های واقعی تبعی ۲۰ درصد («همیار») و ۳۰ درصد («هموطن») با شرط نگه‌داشتن سبد پایه.
